# OrçaVidro — instaladores

Este repositório guarda apenas os **instaladores do aplicativo OrçaVidro para Windows**.
O aplicativo instalado verifica as versões publicadas aqui e se **atualiza automaticamente**.

**Baixar:** acesse a [última versão](../../releases/latest) e execute `OrcaVidro-Setup-x.y.z.exe`.

> Na primeira instalação o Windows pode exibir o aviso do SmartScreen ("Windows protegeu o computador").
> Clique em **Mais informações → Executar assim mesmo**.
